## Featured Projects

### 🧠 Phase Coupling Decomposition for iEEG Speech Artifacts · [`bci-pcd`](https://github.com/bautipelossi/bci-pcd)
> Brain–Computer Interfaces — UNL, 2026

Open-source Python implementation of Phase Coupling Decomposition (PCD), a supervised spatial filter that removes the acoustic artifact induced by speech in intracranial recordings. Modular pipeline (artifact band estimation, spatial spectral decomposition, phase-coupling optimization) with a `fit`/`transform`/`apply` API, validated stage by stage against the authors' MATLAB code and on simulated data with known ground truth.
